**Classical music generator V3**
Creates music using random numbers and music theory. Essentially starting with selecting instuments, structure, form all the way to selecting harmonies and melodies by selecting random options.

## Running the music generator
- Install requirements `pip install -r requirements.txt`
- Run project
- - `./run.sh` or
- - `PYTHONPYCACHEPREFIX=.cache python -m src.main` or
- - `PYTHONPYCACHEPREFIX=.cache python3 -m src.main`
